Connect your Unraid server to a Nebula mesh network.

1. Open your Unraid web interface and go to **Plugins → Install Plugin**.
2. Paste this link into the URL field:

   ```text
   https://github.com/schererleander/nebula-unraid/releases/latest/download/nebula.plg
   ```

3. Click **Install** and wait for installation to finish.
4. Go to **Settings → Nebula** to set up your connection.
